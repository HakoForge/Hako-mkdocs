# What's in the Box

Every Hako-Core ships with:

- 2 smart powerboards
- Wiring harness — SAS, power button, USB, and backplane cables
- Drive removal tools
- Rack ears with handles

!!! note "Hako-Core Mini"
    The Hako-Core Mini ships with **1 powerboard** (the Mini accepts a single powerboard).
