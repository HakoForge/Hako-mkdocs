# AIO Cooler

The HF-L1 supports a single all-in-one (AIO) liquid cooler. The radiator mounts to the **second fan bracket** (the middle fan row).

## Radiator Compatibility

The HF-L1 can use an optional [power board](https://hakoforge.com/collections/pcbs/products/hakoforge-power-board) for [HakoFoundry](../foundry.md) and PWM fan control. Whether it is installed determines the largest radiator the chassis can fit, since the board takes up space in the middle of the case.

!!! info "Supported Radiator Sizes"
    - **360mm** — supported *without* the optional power board.
    - **240mm** — supported *with* the optional power board installed.

!!! note "Radiator Thickness"
    The maximum radiator and fan thickness depends on your motherboard choice, as board size and layout affect the clearance available in the middle fan row.

See [Fan Installation](fan-installation.md) for more on the middle fan row the radiator mounts to.
